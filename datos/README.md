# Data provenance

Source: UK Department for Energy Security and Net Zero, Average road fuel sales, deliveries and stock levels, 8 October 2026 edition.

- [Original workbook](https://assets.publishing.service.gov.uk/media/6ac517e0d9c21d62c02267f6/20261008_Average_road_fuel_sales_deliveries_and_stock_levels.xlsx)
- Original workbook MD5: `29a3357416c55d3eab9c88505b669d74`
- Sheet: `Main table - sales`; range A8:Q7316; fuel type Petrol; column United Kingdom.
- Derived CSV: date, sales in litres, weekday (1 = Monday, 7 = Sunday). 366 observations from 2024 and 365 from 2025.
- The workbook is omitted from version control because the original analysis script downloads it when needed.
